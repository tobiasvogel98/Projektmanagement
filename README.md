# Projektmanagement – Professionelles Lernprogramm

Deutschsprachiges Lernprogramm zum Bau- und Projektmanagement auf Grundlage von
[MIT OpenCourseWare 1.040 Project Management, Spring 2004](https://ocw.mit.edu/courses/1-040-project-management-spring-2004/)
(Dr. Nathaniel Osgood). Lizenz der Inhalte: [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

**Website:** https://tobiasvogel98.github.io/Projektmanagement/

- 6 Lerneinheiten mit 18 vollständig übersetzten Kapitelseiten
- Semesterprojekt in 4 Phasen mit übersetzten Aufgabenstellungen
- Original-Foliensätze (PDF, englisch) und Literaturverzeichnis

Das Deployment auf GitHub Pages erfolgt automatisch bei jedem Push auf `main`
(`.github/workflows/pages.yml`).
